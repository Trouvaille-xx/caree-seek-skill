# 分析方法与口径（analysis methods）

所有计算在 `scripts/analyze.py` / `scripts/match.py` 中实现。**薪资主口径为月薪**（K/月），年包仅作折算参考。

## 1. 基础清洗

- **月薪中值** =（标称下限 + 上限）/ 2；「面议/日薪」不计入薪资统计。
- **折算月薪** = 月薪中值 × 薪数 ÷ 12；薪数缺失按 12。
- **区间宽度** = 上限 − 下限；宽度越大，中值单点误差越大（约 ±宽度/2）。
- **经验要求**：解析 `a-b年`、`a年以上`、`应届/不限`；缺失时该岗位不进入经验分组。
- **学历**：博士 > 硕士 > 本科 > 大专 > 中专 > 高中；「不限」单独保留。
- **城市/区域**：`上海·浦东新区` 拆为城市与区域。

## 2. 薪资分布

- 固定 10 箱（K/月）：`<10`、`10–15`、`15–20`、`20–25`、`25–30`、`30–35`、`35–40`、`40–50`、`50–60`、`60+`；空箱不输出。
- **报价模板频次**：统计原始薪资文本（如 `15-25K`、`30-60K·16薪`）的出现次数与区间跨度。
- **薪数分布**：12 / 13 / 14 / 15 / 16 / 17 / 18 薪。
- 报告中同时给出 P25 / P50 / P75 / 均值，以及折算月薪的 P25 / P50 / P75。

> Boss 的薪资是有限模板的离散混合，**不要做 KDE 或平滑**；双峰之间的凹陷通常是模板间隙，不是市场真空。

## 3. 分层统计

对以下维度分别输出样本数、min、P25、中位、P75、max：

- 经验要求（1–3年 / 经验不限 / 在校应届 / 3–5年 / 5–10年 / 未标注）
- 口径（核心 1–3年 / 扩展 经验不限·应届 / 其他）
- 融资阶段（未融资 / 天使轮 / A / B / C / D轮及以上 / 已上市 / 不需要融资 / 未披露）
- 公司规模（0–20 / 20–99 / 100–499 / 500–999 / 1000–9999 / 10000+ / 未披露）
- 行业、区域、学历、是否脱敏

## 4. 技能与 JD

- **技能打标**：用 `references/skill-dictionary.json` 匹配 JD 文本；英文别名按单词边界。
- **技能命中**：出现该技能的岗位数与覆盖率。
- **技能溢价** = 出现该技能的岗位月薪中位 − 整体月薪中位。
- **入场券 vs 溢价**：高频但溢价 ≤1K 的列为「入场券」；高溢价列为「溢价项」。
- **JD 字数**：字数分布 + 与月薪的 Pearson 相关系数；接近 0 说明字数不预示薪资。

## 5. 职级推断（启发式）

按标题关键词优先级：管理（总监/主管/负责人/组长/leader/head）> 专家 > 资深 > 高级 > 初级 > 中级 > 实习/应届。
标题无信号时按经验下限回退：≤1 初级；≤3 中级；≤5 高级；≤8 资深；否则专家。
「产品经理」「项目经理」中的“经理”是岗位名，不参与管理职级判断。

## 6. 四种阶梯

- **同司职级**：同公司按职级排序，输出各级中位、样本数与级差；≥3 级且样本 ≥6 才标 ok。
- **跨司对标**：岗位数前 12 家公司 × 职级矩阵，单元格为中位与样本数。
- **能力地图**：技能频次、出现时月薪中位、溢价、主要职级。
- **薪资曲线**：按经验下限分桶（0–1 / 1–3 / 3–5 / 5–8 / 8+），输出 P25/中位/P75。

## 7. 岗位匹配分（无简历时）

`match_score = 关键词覆盖 40 + 薪资契合 25 + 城市 15 + 经验 10 + 公司背调置信度 10`。
用于岗位总表排序，不代表简历匹配。

## 8. 简历匹配分（有简历时）

`总分 = 技能 40 + 经验 20 + 学历 10 + 薪资 15 + 城市 5 + 方向 10`。
校招/应届岗对资深候选人降档；明显高于经验上限也降档。
冲 ≥75、稳 60–74、保 45–59、<45 不推荐。

## 9. 置信度提示

会触发 `low_confidence_flags` 的情况：
- 有效薪资样本 <20；
- 缺失薪资 >30%；
- JD 覆盖率 <50%；
- 区间宽度中位 >8K（中值误差大）；
- 创始人姓名覆盖率 <60%。

## 10. 已知局限

- JD 职级披露参差，职级推断为关键词启发式。
- 薪资是标称区间，非实际 offer；同一职级差异可能来自个人谈判与股票期权。
- 技能打标是词典匹配，新技能可能漏标；可扩展词典。
- 融资阶段/公司规模常缺失（尤其脱敏大厂），分组结论需结合样本量看。
