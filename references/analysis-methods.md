# 分析方法与口径（analysis methods）

所有计算在 `scripts/analyze.py` / `scripts/match.py` 中实现。**薪资主口径为月薪**（K/月），年包仅作折算参考。

## 1. 基础清洗

- **月薪中值** =（标称下限 + 上限）/ 2；「面议/日薪」不计入薪资统计。
- **折算年薪** = 月薪中值 × 薪数（K/年）；薪数缺失按 12。
- **区间宽度** = 上限 − 下限；宽度越大，中值单点误差越大（约 ±宽度/2）。
- **经验要求**：解析 `a-b年`、`a年以上`、`应届/不限`；缺失时该岗位不进入经验分组。
- **学历**：博士 > 硕士 > 本科 > 大专 > 中专 > 高中；「不限」单独保留。
- **城市/区域**：`上海·浦东新区` 拆为城市与区域。

## 2. 薪资分布

- 固定 10 箱（K/月）：`<10`、`10–15`、`15–20`、`20–25`、`25–30`、`30–35`、`35–40`、`40–50`、`50–60`、`60+`；空箱不输出。
- **报价模板频次**：统计原始薪资文本（如 `15-25K`、`30-60K·16薪`）的出现次数与区间跨度。
- **薪数分布**：12 / 13 / 14 / 15 / 16 / 17 / 18 薪。
- 报告中同时给出 P25 / P50 / P75 / 均值，以及折算年薪的 P25 / P50 / P75。
- **折算年薪分布**：不沿用月薪固定 10 箱，按数据跨度选择整齐步长（1/1.5/2/2.5/3/4/5/6/8/10 × 10ⁿ），空箱不输出；图上按「万/年」展示。

> Boss 的薪资是有限模板的离散混合，**不要做 KDE 或平滑**；双峰之间的凹陷通常是模板间隙，不是市场真空。

## 3. 分层统计

对以下维度分别输出样本数、min、P25、中位、P75、max：

- 经验要求（1–3年 / 经验不限 / 在校应届 / 3–5年 / 5–10年 / 未标注）
- 口径（核心 1–3年 / 扩展 经验不限·应届 / 其他）
- 融资阶段（未融资 / 天使轮 / A / B / C / D轮及以上 / 已上市 / 不需要融资 / 未披露）
- 公司规模（0–20 / 20–99 / 100–499 / 500–999 / 1000–9999 / 10000+ / 未披露）
- 行业、区域、学历、是否脱敏

### 3.1 市场公司调研

岗位统计之外，单独按 **公司** 做一层市场调研（`analysis.company_research`）：

- **融资阶段**：按公司计数，辅以该组岗位的月薪中位；行业列混入「A轮/天使轮」等值时自动归位到融资字段。
- **领域分布**：按公司计数；长尾并入「其他」，未披露单列。
- **企业规模（人数）**：0–20 / 20–99 / 100–499 / 500–999 / 1000–9999 / 10000+ / 未披露。
- **公司年龄**：按成立年份计算，分桶 ≤3 年 / 3–5 年 / 5–10 年 / 10–20 年 / 20 年+ / 未披露。
- **行业 × 融资阶段**：热力图，颜色深浅 = 公司数；按公司计数，不按岗位数加权。
- **招聘集中度**：Top 5 / Top 10 公司岗位占比、单岗位公司占比、HHI（越高越集中）。

> 公司调研是本次检索样本的结构，不代表全市场；覆盖率（融资 / 领域 / 成立年份）要在结论中明示。

## 4. 技能与 JD

- **技能打标**：用 `references/skill-dictionary.json` 匹配 JD 文本；英文别名按单词边界。
- **技能命中**：出现该技能的岗位数与覆盖率。
- **技能溢价** = 出现该技能的岗位月薪中位 − 整体月薪中位。
- **能力投资象限**：x = 岗位覆盖率，y = 薪资溢价；用覆盖率中位数与 0 溢价切四象限，右上为优先投入，高频低溢价为入场券，低频高溢价为差异化。
- **技能组合**：同一岗位内的技能两两共现，按岗位数排序，附组合岗位的月薪中位与溢价；组合比单技能更能说明岗位真正要什么。
- **入场券 vs 溢价**：高频但溢价 ≤1K 的列为「入场券」；高溢价列为「溢价项」。
- **JD 字数**：字数分布 + 与月薪的 Pearson 相关系数；接近 0 说明字数不预示薪资。
- **岗位关键词云**：标题去空格后按标点切词，叠加技能标签；同一岗位同一关键词只计一次。字号按频次平方根缩放，避免高频词挤占整个画布。

## 5. 职级推断（启发式）

按标题关键词优先级：管理（总监/主管/负责人/组长/leader/head）> 专家 > 资深 > 高级 > 初级 > 中级 > 实习/应届。
标题无信号时按经验下限回退：≤1 初级；≤3 中级；≤5 高级；≤8 资深；否则专家。
「产品经理」「项目经理」中的“经理”是岗位名，不参与管理职级判断。

## 6. 四种阶梯

- **同司职级**：同公司按职级排序，输出各级中位、样本数与级差；≥3 级且样本 ≥6 才标 ok。
- **跨司对标**：岗位数前 12 家公司 × 职级矩阵，单元格为中位与样本数。
- **能力地图**：技能频次、出现时月薪中位、溢价、主要职级。
- **薪资曲线**：按经验下限分桶（0–1 / 1–3 / 3–5 / 5–8 / 8+），输出 P25/中位/P75。

## 7. 岗位匹配分（无简历时）

`match_score = 关键词覆盖 40 + 薪资契合 25 + 城市 15 + 经验 10 + 公司背调置信度 10`。
用于岗位总表排序，不代表简历匹配。

## 8. 简历匹配分（有简历时）

`总分 = 技能 40 + 经验 20 + 学历 10 + 薪资 15 + 城市 5 + 方向 10`，启用通勤时再按超出程度扣 5–20 分。
校招/应届岗对资深候选人降档；明显高于经验上限也降档。
冲 ≥75、稳 60–74、保 45–59、<45 不推荐。

### 8.1 老板 / 团队背景评分

`analyze.py` 基于公开履历文本做规则评分（0–100），用于背调参考，不是能力定论：

- 基础分 44（有创始人/团队履历）；
- 名企 / 大厂 / 头部机构：每项 +10，上限 30；
- 顶级高校：每项 +12，上限 24；
- 高管 / 创业角色：每项 +6，上限 18；
- 硕博 / MBA / 海归 / 连续创业 / 上市或 500 强：每项 +5，上限 15；
- 知名企业家共事/投资：每项 +6，上限 12；
- 背调置信度：high +10 / med +5；
- 等级：≥80 强 / ≥60 较好 / ≥45 一般 / <45 有限；无履历 = 未评估。

每条评分输出 `signals`（如「名企：腾讯、麦肯锡」「高校：斯坦福」）便于追溯。关键词规则会漏掉没有被文字记录的优秀背景，结论必须带「线索，不是定论」。

## 9. 推荐结论（薪资 + 通勤）

设用户期望月薪下限为 `E`（如 18K）：

- **推荐**：岗位上限 `>= E × 0.95` 或岗位中位 `>= E × 0.9`。
- **可考虑**：岗位上限 `>= E × 0.85` 或中位 `>= E × 0.8`（略低）。
- **不推荐**：低于上述下限。例：`E=18K` 时 6–12K、12–15K 不推荐；15–20K、18–20K 可推荐。

通勤（启用且已计算时）：

- `<= max_minutes`：匹配；
- `<= max_minutes × 1.2 + 10`：略超，「可考虑」；
- `<= max_minutes × 1.5`：「可考虑（偏弱）」；
- `> max_minutes × 1.5`：不推荐；
- 未计算：`待核实`，不能声称通勤匹配。

汇总状态：

- 推荐 ≥5 个 → `ok`；
- 有推荐 / 可考虑 / 待核实 → `partial`；
- 全部不推荐 → `insufficient`，必须写期望 vs 实际、原因与调整建议，不伪造、不硬凑。

## 10. 置信度提示

会触发 `low_confidence_flags` 的情况：
- 有效薪资样本 <20；
- 缺失薪资 >30%；
- JD 覆盖率 <50%；
- 区间宽度中位 >8K（中值误差大）；
- 创始人姓名覆盖率 <60%；
- 启用通勤但仍有岗位未计算（结论降为「待核实」）。

## 11. 已知局限

- JD 职级披露参差，职级推断为关键词启发式。
- 薪资是标称区间，非实际 offer；同一职级差异可能来自个人谈判与股票期权。
- 技能打标是词典匹配，新技能可能漏标；可扩展词典。
- 融资阶段/公司规模常缺失（尤其脱敏大厂），分组结论需结合样本量看。
